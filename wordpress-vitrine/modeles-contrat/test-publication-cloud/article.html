À quoi sert cette page de test ?

Cette page est temporaire. Elle sert uniquement à vérifier que Lumen Juris peut construire et publier une page depuis le cloud, sans ordinateur local.

Ce que le test vérifie

ÉlémentVérification attendue
ConstructionLes fichiers du modèle sont générés dans le cloud.
WordPressLa page est publiée sur www.lumenjuris.com.
DisponibilitéLa page répond en HTTP 200.
Micro-donnéesLe balisage généré par le système est présent.
Plan du siteL'adresse apparaît dans le sitemap WordPress.

Périmètre du test

Le test concerne uniquement le site vitrine www.lumenjuris.com. Il ne modifie pas l'application app.lumenjuris.com et ne change aucun réglage global du site.

Que se passe-t-il en cas d'erreur ?

Si WordPress renvoie une erreur ou si une vérification échoue, le test est considéré comme non concluant et la routine doit être corrigée avant toute publication quotidienne.

Après le test

Une fois la chaîne cloud validée, cette page temporaire doit être retirée du site public.
